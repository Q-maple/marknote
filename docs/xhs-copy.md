## 二、正文（直接复制）

每天读长文的人应该都有这个痛点👇

划了线，第二天就忘了当时为什么划；想查一句什么意思，还得复制粘贴切到另一个窗口去问。

所以我自己写了个浏览器插件，叫 **MarkNote**，免费用、不用注册。用了一个多月，说说几个让我回不去的点：

🖍 **划线这件事做得很细**
5 种颜色 + 自定义颜色，色环、RGB、系统吸管都能调，调好的颜色能存成常用色板。
标签支持斜杠分多级，比如「技术/前端/性能」，输过一次以后自动补全。

🔢 **划线会自动编号**
网页上的 1、2、3 和侧边栏清单里的编号一一对应。读那种上万字的长文，再也不用想「我刚才划的是哪句」。

🤖 **划完直接问 AI**（我最喜欢的功能）
选中一句话 → 工具条上点「对话」→ 旁边冒出一个**可以拖着走的小窗**，直接跟 AI 聊这段文字。
它是**多轮**的，可以一直追问，不用每次重新解释背景。
特别说一下：**它只会跟你聊，不会自己给你乱加划线**；关掉窗口对话就清空，不存任何东西。
模型可以换：DeepSeek、豆包（火山方舟）、腾讯混元，或者任何 OpenAI 兼容接口——用的是**你自己的 API Key**。

🧹 **手滑也不怕**
一键清空本页划线，9 秒内点「撤销」能原样找回来。

🔒 **关于隐私（这条我最在意）**
不用注册账号，也没有云端账号；不收集数据、没有埋点；划线只存在你自己的浏览器里，**卸载即清空**。
AI 功能默认关闭，只有你自己点「分析 / 发送」时才会请求，而且请求是直接发给你自己配置的接口，**不经过我这边**。
有独立的隐私政策，把「唯一会联网的功能」「权限用在哪」都写清楚了。

📤 导出的格式是 Markdown / 纯文本 / JSON，丢进 Obsidian、思源、Logseq 都能读。

## 四、置顶评论（发布后自己顶上去）

> 补充几个常被问的点 👇
> ① 免费、不用注册，Chrome / Edge / Firefox 都能装；
> ② AI 功能**默认关闭**，要自己去管理页填 API Key（用你自己的账号，一次分析几分钱），不想用就一直不用打开；
> ③ 划线数据只存在你本机，**卸载扩展会清空**，记得偶尔用「导出 JSON 备份」留档；
> ④ 安装方式：扣「划线」我私信发你（站内，不加微信）。

## 五、发布建议

- **封面用第 1 张**（大字 + 荧光笔意象），第 2、3、4 张按顺序做轮播；第 3 张（AI 对话）是转化最高的一张，别放最后。
- **时间**：工作日 12:00–13:00 或 20:00–22:30。
- **正文首行别放链接或敏感词**，避免被判引流；引导只写「评论区扣关键词」。
- 简介/评论里不要出现微信号、二维码、站外地址——这是小红书最容易限流的点。
- 有人问「和某某插件比怎么样」时，**别主动提竞品名字**（容易被举报），说「看你更在意云同步还是本地」更安全。
