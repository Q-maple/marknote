# MarkNote · 网页划线高亮批注

一个**免费、开源、数据只存在本机**的浏览器扩展：在任意网页上多色划线、写批注、打标签、导出 Markdown。
Manifest V3，同时在 **Firefox** 和 **Chrome / Edge / Brave** 上可用。

> 这是照着「五彩（Wucai）」的功能清单**从零重写**的独立实现。
> 五彩是「保留所有权利」的闭源扩展，所以这里没有使用它的任何代码、图标或品牌名——只是把它的功能点重新实现了一遍，
> 并去掉了它的云端同步（改成纯本地 + JSON 备份）。详见文末「与五彩的关系」。

当前版本 **1.6.1**，各版本改了什么看 [CHANGELOG.md](CHANGELOG.md)。

**仓库**：<https://github.com/Q-maple/marknote> · **下载安装包**：[Releases](https://github.com/Q-maple/marknote/releases/latest)

## 一、功能

| 能力 | 说明 |
| --- | --- |
| 多色高亮 | 5 种内置色（黄 / 绿 / 蓝 / 粉 / 紫），选中文字后在浮动工具条上点一下即可 |
| 自定义颜色 | 工具条 / 弹窗里的彩色小方块打开取色器：色环 + 饱和明度方块 + RGB / HEX 输入 + 系统取色器，调好的颜色可以「存为常用色」长期留在色板上（点 × 或右键即可删除） |
| 刷新不丢 | 划线用「文字 + 前后文 + 偏移」三重定位，页面改版、内容位移后仍能重新找到 |
| 批注 | 每条划线都能写笔记，右侧常驻工具条上还有数量统计 |
| 无限层级标签 | 用 `/` 分隔即可，例如 `技术/前端/性能`，输入时自动补全已有的标签 |
| 数量无上限 | 每页、每站、总量的划线数都不设限制 |
| 图片标记 | 右键图片 → 「标记这张图片」，同样可以加笔记和标签 |
| 划线序号 | 想让「划线清单里的 3 号」和「网页上那块高亮」对得上？在管理页「高亮序号」里打开序号即可（排序可选「按页面位置」或「按创建时间」）。序号是画在高亮上的，不写进正文，不影响原文，也不影响定位 |
| 一键清空 | 弹窗 / 侧边栏里「清空本页划线」一键清掉当前页（清完页面里还有 9 秒「撤销」）；管理页「清空全部划线」清掉所有网站，清完也能撤销。动手前建议先导出 JSON 备份 |
| 划线的组织 | 侧边栏看本页清单；管理页按文字 / 笔记 / 标签 / 网站 / 颜色筛选，可批量删除 |
| 导出 | Markdown（引用式 / 列表式）、纯文本、JSON 备份；都能一键复制或下载 |
| 导入 | 导入 JSON 备份，用来换电脑、同步多台设备 |
| AI 智能标注 | **可选**：接任意 OpenAI 兼容接口（DeepSeek / 火山方舟豆包 / 腾讯混元 等），选中文字 + 一句提示词，AI 给出「该划哪里 + 批注什么 + 用什么颜色」，你勾选完再一键写入。**模型不用手填**：填好 API Key 保存一次，插件会自动拉取这个接口的模型列表并选第一个；之后在网页上的 AI 面板 / 对话窗里随时能换。密钥只存本机，默认关闭。与这些服务商**无官方合作**，生成内容请自行核对 |
| AI 对话（悬浮窗） | **可选**：选中文字或点某条已有划线 → 工具条 / 弹层 / 右键菜单 → 弹出一个可拖动的悬浮小窗，就这段文字和 AI **连续多轮对话**（解释、翻译、追问都行）。**它只聊天，永远不产生划线**；对话只活在窗口里，关掉即清空，不落库、不进导出 |
| 复制辅助 | **默认关闭**：某些网页自己禁用了选中或复制时，可在弹窗里「允许本页选中复制」，让你仍能复制正在看的内容（只作用于你自己的浏览器，首次使用会提示确认）。请遵守目标网站的使用条款 |
| 快捷键 | `Alt+Shift+H` 高亮 · `N` 加笔记 · `C` 复制 · `A` AI 分析 · `S` 侧边栏 · `X` 隐藏高亮 |
| 夜间模式 | 界面跟随系统深浅色 |

**隐私**：不收集任何数据、没有账号、没有埋点；详见 [PRIVACY.md](PRIVACY.md)（扩展内也能离线查看：管理页 / 弹窗里的「隐私政策」）。

**没有的**：云端同步（五彩的付费点）、Obsidian / Logseq / 思源笔记的直接对接、PDF 内划线。

## 二、安装

> 现成的包在 [Releases](https://github.com/Q-maple/marknote/releases/latest) 里下载：
> `marknote-firefox.zip`（Firefox）、`marknote-chrome.zip`（Chrome / Edge / Brave）。
> 不想用打好的包，就 `git clone` 本仓库后跑 `./tools/build.sh` 自己打一份。

### Firefox

1. 解压 `marknote-firefox.zip`（或直接用源码目录 `marknote/`）。
2. 地址栏输入 `about:debugging#/runtime/this-firefox`。
3. 点「临时载入附加组件」→ 选择解压目录里的 **manifest.json**。

> 临时载入在重启浏览器后会消失（调试用）。**想持久安装**——重启后还在、能长期用——
> 见 [docs/firefox-persistent-install.md](docs/firefox-persistent-install.md)：
> 正式版走 AMO 自助签名（免费、不用上架），不想注册账号就用 Developer Edition / Nightly 关掉签名检查。
> 两条路都已经写成可照着做的步骤，含数据备份与排查对照表。
> 走 AMO 自助签名的完整操作（网页版 / 命令行版）见
> [docs/amo-self-signing-steps.md](docs/amo-self-signing-steps.md)，
> 配套脚本：`./tools/sign-firefox.sh`。

### Chrome / Edge / Brave

1. 解压 `marknote-chrome.zip`。
2. 打开 `chrome://extensions`，右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压出来的目录。

> 注意：**两个浏览器的包不能混用**。Chromium 的清单解析里写明
> `background.scripts` 和 `background.service_worker` 不能同时出现（否则直接加载失败），
> 而 Firefox 又不支持 MV3 的 `service_worker`，所以仓库里用 `tools/make-chrome-manifest.py`
> 从 `manifest.json` 派生出 Chromium 专用的清单。改完源码跑 `tools/build.sh` 重新打包即可。

## 三、怎么用

**给文字划线**：选中文字 → 浮出工具条 → 点颜色。四种入口任选：

- 选中文字后的浮动工具条
- 右键菜单「MarkNote：高亮选中文字」
- 快捷键 `Alt+Shift+H`
- 页面右侧常驻小工具条上的色点（点到当前选中的文字上）

**换个颜色 / 自定义颜色**：工具条（或批注弹层、弹窗）上最右边那个**彩色小方块**打开取色器——

- **色环**：拖外圈选色相，拖右边的方块调饱和度和明暗；
- **RGB / HEX**：直接往 R、G、B 三个框里填数字，或敲 `#3b5bdb`，两边实时同步；
- **系统取色器**：点「系统」调出操作系统自带的色轮 / 吸管；
- **存为常用色**：调好点一下，这个颜色就常驻色板，以后一点就能用；
- **删掉常用色**：色板里的自定义色，鼠标移上去点右上角的 `×`，或者直接右键（删除只是不再出现在色板里，**已经划好的线不受影响**）；
  弹窗的「常用自定义色」列表里每个色块后面也有一个 `×`。

取色器在「没选中文字」时点是改**默认颜色**；选中了文字就是**新建划线**；已经点开某条高亮的批注弹层时则是**改这条划线的颜色**。
自定义颜色直接以 `#rrggbb` 存在划线数据里，常用色板删掉也不影响已经划好的线。

**AI 智能标注（可选）**：先到管理页最下面的「AI 分析（第三方接口）」卡片里填上 API Key、打开开关。

**模型怎么来的**：模型名是跟着服务商走的（DeepSeek 是 `deepseek-chat`，火山方舟是接入点 ID `ep-…`，腾讯混元是
`hunyuan-turbos-latest` 这类），所以代码里**不写死**。你填完 API Key 点「保存 AI 设置」时，插件会自动问一次
`GET /models`，把**第一个**设成默认值；想换的话有两条路：

- 管理页里点「拉取可用模型」，然后点某个标签；
- **直接在网页上换**：AI 分析面板标题栏、AI 对话悬浮窗标题栏上都有一个可点的模型名，点开就是模型列表
  （带「重新拉取」，5 分钟内复用缓存），选谁立刻生效、并保存为本机默认——分析和对话共用同一份设置。

要是这个接口没有 `/models`（比如火山方舟），自动拉取会失败并提示你手填模型名，这不影响其它功能。
（不想先配 Key？直接打开 [docs/ai-preview.html](docs/ai-preview.html) 就能看到面板长什么样——那是真实的
`content.js` 加一份假的扩展 API，演示数据写死，不会联网。）然后——

- 选中一段文字 → 工具条上点 **AI**（或右键「用 AI 分析选中文字」、快捷键 `Alt+Shift+A`、侧栏上的 ✦）；
- 面板里可以改一句提示词（比如「只挑和价格有关的」），旁边的范围可以切成「整页正文」；
- 点「开始分析」，AI 会把该划的地方列出来：**原文片段 + 颜色 + 一句批注**，每条都能改批注、能取消勾选；
- 点「写入划线」——之后它们就是普通的划线，颜色、标签、笔记、导出都和手划的一模一样。

页面上找不到原文的片段会被标出来并自动禁选（比如内容是懒加载的）。已经划过的同一句会自动跳过。
AI 只是「替你先划一遍」，不会在你没点的时候做任何事；每次分析只发送你选中的那段文字（或整页正文，看范围）。

**和 AI 聊几句（不划线）**：选中一段文字 → 工具条上点 **对话**（或右键「MarkNote：和 AI 讨论选中的文字」、弹窗里「AI 对话选中文字」）；
已经划过线的地方，直接点那条高亮 → 弹层里的 **AI 对话**，引用就是这条划线的原文。
打开的悬浮小窗可以**按住标题栏拖动**，右侧锁着一条引用原文的小胶囊，输入框 `Enter` 发送、`Shift+Enter` 换行。

- **输入框里预填了一句默认提示词**（「帮我解释这段文字的意思，并指出其中的重点。」，可在管理页改）：
  不动它直接点发送，就按这句问；一开始打字，它整段让位给你自己写的问题——不管是接在末尾写、全选替换，还是插在中间，都只留下你写的那部分；
- 这是**多轮**对话：后面的问题会带上前面的一问一答，可以一直追问下去；
- **它不产生任何划线**——窗口里没有「写入划线」按钮，聊完你的划线一条都不会变；
- 对话**只存在于这个窗口**：点 ✕、按 `Esc`、换页、刷新都会清空，重新打开就是新对话；
- 内容会随每一轮发给你配置的那个接口（引用的文字 + 对话历史），和 AI 分析用的是同一份 Key / 模型设置。

**写批注**：点已有的高亮，或右键「高亮并写笔记」，在弹层里写笔记、加标签（回车确认，支持 `A/B/C` 多级）、改颜色，`⌘/Ctrl + Enter` 保存。

**看和整理**：右边缘的小圆条 → ☰（本页清单，Firefox 里是真侧边栏）或工具栏图标 → 「管理 / 导出」。
管理页支持按标签树筛选、全选删除、导出 Markdown/JSON。

**给划线编号**：管理页最下面的「高亮序号」卡片里打开开关，每条高亮前面就会出现 1、2、3……
- 排序方式两种：**按页面里的位置**（从上到下，默认）或**按创建时间**（先划的在前）；
- 侧边栏清单里每条也会标上同一个号，翻长文时两边互相找；
- 关掉就全部消失。编号只是个标记（用 CSS 画在原来是文字的位置），**不会改动网页正文**，导出也不受影响。

**清空划线**：
- **清空本页**：点扩展图标 → 「清空本页划线」，或侧边栏右上角的 🗑（都会先问一句「清空本页的 N 条？」）。
  清完页面底部会弹一条「已清空本页 N 条划线 · 撤销」，**9 秒内点「撤销」就能原样找回**；
- **清空全部**：管理页最下面「清空划线」卡片 → 「清空全部划线」，会把所有网站的数据一起删掉（会报出条数和页面数，
  并提醒先导出备份）。清完同一个位置会出现「撤销」按钮，原样写回。
- 想更保险就先去「管理 / 导出」里「导出 JSON 备份」——**导出的文件是唯一的后悔药**（卸载扩展会清空本地数据）。

**备份与换设备**：管理页 → 「导出 JSON 备份」；在新设备上「导入 JSON 备份」。
数据在 `chrome.storage.local` 里，扩展卸载即清空，请定期导出。

```
marknote/
├── manifest.json                 # Firefox 清单（也是唯一事实来源）
├── PRIVACY.md / privacy.html     # 隐私政策（Markdown 版与扩展内可离线打开的 HTML 版，两处要同时改）
├── tools/
│   ├── make-chrome-manifest.py   # 派生 Chromium 清单
│   └── build.sh                  # 打两个可直接加载的 zip
├── icons/                        # 16/32/48/96/128 图标（脚本生成的 PNG）
├── src/
│   ├── common/
│   │   ├── util.js               # 颜色解析 / 自定义色板、标签树、时间、复制、Markdown 导出
│   │   ├── picker.js             # 取色器（色环 + 饱和明度方块 + RGB / HEX + 常用色板）
│   │   ├── ai.js                 # ★ AI：配置归一化、提示词、请求、解析模型返回的 JSON
│   │   ├── store.js              # chrome.storage.local 封装（一条划线一个 key）
│   │   ├── anchors.js            # ★ 文本定位引擎（序列化 / 还原 / 包裹 / 拆包）
│   │   └── pages.css             # 扩展页面共用样式
│   ├── content/
│   │   ├── content.js            # ★ 页面内的一切：工具条、批注层、右侧小工具条、复制辅助
│   │   └── content.css           # 高亮的页面级样式
│   ├── background/background.js  # 右键菜单、快捷键、打开侧边栏/管理页、代发 AI 请求（跨域）
│   ├── sidebar/                  # 本页划线清单
│   ├── dashboard/                # 全部划线的搜索 / 筛选 / 导出 / 导入 + AI 设置
│   └── popup/                    # 工具栏弹窗
└── test/                         # 7 个 Node + jsdom 测试（806 项断言）
```

### 定位引擎是怎么工作的

1. 把页面文字按「可见文本节点」拼成一条虚拟长文本，每个节点记下 `[start, end)`。
2. 划线时记录 `exact`（选中的文字）、`prefix` / `suffix`（前后各 40 字）、以及虚拟偏移 `startV` / `endV`。
3. 还原时按 `prefix+exact+suffix` → `prefix+exact` → `exact+suffix` → 所有 `exact` 中出现位置（取离 `startV` 最近的一处）→ 纯偏移兜底 的顺序尝试。
4. 命中后用 `splitText` 精确切开文本节点，包一层 `<mark class="mn-hl">`；重新渲染前把 `<mark>` 拆掉并 `normalize()` 还原成原始文本。

被跳过、不参与定位的内容：`script/style/textarea/input/select/iframe/canvas/svg` 和 `contenteditable` 区域。

## 六、AI 与隐私

- **默认关闭**：不填 Key、不打开开关，扩展就永远不联网。
- 开启后，只有你**主动**点「开始分析」时才会发一次请求；请求发往**你自己配置**的那个接口，只带两样东西：
  选中的那段文字（或整页正文）＋ 提示词。划线数据、标签、笔记历史都不会上传。
- **API Key 存在本机** `storage.local` 的 `aiKey` 里，单独一个键，不进 `settings`，因此**不会**跟着
  「导出 JSON 备份」走，界面上也只显示成 `sk-••••尾四位`。想清掉随时点「清除 Key」。
- 走的是你自己的 DeepSeek 账号，费用按 DeepSeek 的价目表算（一次分析通常几厘到几分钱）。
  余额不足 / Key 不对 / 网络不通时，会把服务端返回的原话直接显示在管理页和页内面板上，方便定位。
- 因为「开启后会把网页内容发给第三方」，`manifest.json` 里如实声明了
  `browser_specific_settings.gecko.data_collection_permissions.required = ["websiteContent"]`
  （Firefox 140+ 安装时会据此提示；扩展本身不会在后台偷偷发任何东西）。
- 换模型 / 换服务商：任何 OpenAI 兼容的 `/chat/completions` 都能用——把「接口地址」改成你自己的即可，
  例如本地 Ollama 填 `http://localhost:11434/v1`。
- **第三方商标**：MarkNote 与 DeepSeek（深度求索）、OpenAI 等**没有隶属、代理或合作关系**；界面与文档里出现
  这些名字只为说明「兼容哪个接口」。不要把对方的 logo 放进商品图或应用截图里。

### 常见的两类报错

| 报错 | 原因 | 怎么办 |
| --- | --- | --- |
| `The supported API model names are …` | 模型名跟这个接口对不上（不同服务商、不同代理叫法不一样，官方是 `deepseek-chat`） | 管理页点一下 **「拉取可用模型」**（它会去问 `/models`），把列出来的名字点一下填进「模型」框，保存即可。测试连接或分析失败时，报错后面会自动附上这个接口支持的模型名 |
| `Prompt must contain the word 'json' …` | 用了 `response_format: json_object`，接口就要求请求里出现 json 这个词 | 正常情况下不会遇到：分析用的提示词里本来就写了「只输出一个 json 对象」。如果你把「强制 JSON 输出」配给了一个更严格的端点，把这个开关关掉即可（关掉后靠提示词约束，解析层照样能兜住） |

> 「测试连接」按钮**不**走 JSON 模式，只验证地址 / Key / 模型名这三件事，所以它不会被上面第二类问题连累。

## 七、与五彩的关系（重要）

- 五彩扩展的许可协议是 **保留所有权利（All rights reserved）**，它的代码、图标、名称都不能拿来用。
- MarkNote 是**照着功能清单的独立重写（clean-room）**：所有代码、样式、图标都是新写的，也刻意换了名字和主色。
- 因此**没有**：五彩账号、云端同步、手机端、Obsidian/Logseq/思源 的直连，以及它那种「走官方云端、替你花钱」的 AI。
  MarkNote 的 AI 是**自带 Key** 的路子：请求直接发给你自己配置的接口，不经过任何中间服务器。
- 需要「多终端同步」的话，用管理页导出 JSON，再在另一台机器导入——效果等价，只是要手动点一下。
