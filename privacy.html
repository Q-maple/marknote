MarkNote 隐私政策

版本 1.6.2 ｜ 生效日期 2026-01-01 ｜ 适用：MarkNote 浏览器扩展（Firefox / Chrome / Edge / Brave）
一句话：MarkNote 没有服务器、没有账号、没有统计埋点。你划的线只存在你自己的浏览器里； 只有你主动点「AI 分析」时，选中的文字才会发给你自己配置的那个接口。

一、我们不收集任何数据

  • 没有账号体系：不需要注册登录，也不收集邮箱、手机号等身份信息；
  • 没有开发者服务器：扩展不会把数据发回给我们，也没有任何中转；
  • 没有统计分析 / 埋点 / 崩溃上报：不记录你访问了哪些网页、划了多少线、点了哪些按钮；
  • 没有广告、没有第三方 SDK：安装包里只有 MarkNote 自己的代码。

二、你的数据存在哪里

  • 高亮、笔记、标签、颜色、设置项全部存在你本机浏览器的 chrome.storage.local 里；
  • 不会同步到任何服务器；卸载扩展（或移除临时载入的扩展）时浏览器会清空这些数据，想留档请用管理页的「导出 JSON 备份」；
  • 导出的文件由你自己保管，注意里面有划线原文和你的笔记。

三、唯一会联网的功能：AI 分析（默认关闭）

只有在开关是开着的 + 自己填了接口和 Key + 手动点了分析时才会联网。填 API Key 时会自动帮你勾上开关（不想要随时取消，取消后不会再替你勾）。发送的内容只有：

发送内容说明
选中的文字（或整页正文）取决于面板里选的范围，只在你点分析时发一次
你写的提示词面板里那句话，可留空
模型参数模型名、温度、最大条数等
悬浮窗里的对话记录 「AI 对话」窗口里每一轮都会把你引用的那段文字 + 到目前为止的对话历史一起发出去（否则模型接不上话）。 这段对话只存在内存里：关掉窗口或刷新页面就没了，既不写进划线，也不进导出文件。

不会发送：浏览历史、其他网页的内容、你的笔记与标签、除 API Key 之外的任何设置。

  • 数据由你的浏览器直接发给你填的那个接口（默认 https://api.deepseek.com），不经过 MarkNote 开发者的任何服务器，我们不经手、不中转、不留存；
  • 对方如何处理这些内容，取决于该服务商自己的隐私政策与服务条款，请只使用你信任的服务商；
  • 数据出境：如果你把接口地址填成境外服务，内容会传输到境外，请自行评估；
  • API Key 单独存在本机的 aiKey 里，不写进设置项、不会出现在导出的备份文件中，管理页可随时清除；
  • 悬浮窗对话不落库：MarkNote 不保存对话内容（连本机也不存），关掉窗口即丢弃；它也不会生成任何划线。

四、权限都用在哪

权限用途
storage / unlimitedStorage在本机存划线、笔记与设置，数量不设上限
<all_urls>划线功能需要在你打开的任何网页上工作（注入工具条、绘制高亮、读取你选中的文字）
tabs弹窗和侧边栏需要知道当前标签页，才能显示「本页」的划线清单
contextMenus右键菜单里的「高亮选中文字」「标记这张图片」等入口
clipboardWrite你点「复制」时把文字写进剪贴板

扩展不会读取你的表单输入、密码、Cookie，也不会修改网页内容（只有你划线的地方会被加上高亮标记）。

五、网站上的版权内容

划线原文来自你访问的网页，版权属于原网站或原作者。MarkNote 只是把这些文字保存在你自己的浏览器里方便你自己查看，请勿把导出内容用于侵犯他人著作权的用途。

六、AI 生成的内容

AI 给出的高亮位置与批注由第三方模型生成，可能不准确甚至有误，请自行核对后采用。

七、商标声明

MarkNote 是独立开发的扩展，与 DeepSeek（深度求索）、OpenAI 及其他被提及的第三方服务没有隶属、代理或合作关系；文档与界面里出现的第三方名称仅用于说明「兼容哪个接口」。

八、关于复制辅助功能

扩展里有一个「允许本页选中复制」的辅助功能，作用范围仅限于你自己的浏览器——当某个网页自己禁用了选中或复制时， 让你仍能选中并复制正在看的内容。该功能默认关闭，首次使用会提示你确认；请遵守目标网站的使用条款， 不要把它用于批量抓取或转载他人内容。

九、未成年人

本扩展不面向未成年人单独提供服务，也不会有意收集未成年人的任何信息（事实上我们不收集任何人的信息）。

十、政策变更

政策如有更新会随扩展新版本一起发布，并在 CHANGELOG 里说明；继续使用新版本即视为接受更新后的政策。

English Summary

  • We collect nothing. No account, no analytics, no telemetry, no developer server, no third-party SDKs.
  • Everything stays on your device in chrome.storage.local; uninstalling removes it.
  • The only network feature is optional AI analysis, off by default. It sends only the text you selected (or the page body, if you choose that scope) plus your prompt, directly to the endpoint you configure with your own key. Your key never leaves your machine and is excluded from exports.
  • Not affiliated with DeepSeek, OpenAI, or any other third-party service mentioned in the UI. AI output may be wrong — verify it yourself.
  • Copy helper: a default-off feature that lets your own browser select and copy text on pages that block it. Please respect the terms of the sites you visit.
